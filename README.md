## Rimplex
Though not many disciplines use them, complex numbers are an important tool in the disciplines that do.
Further, though the mechanics of manipulating complex numbers has been understood for many years, the operations are cumbersome to perform by hand.
As a result, several WWW-based calculators have been created for working with complex numbers. 
However, there are few (if any) complex number calculators that can be run directly on the desktop.

Rimplex is designed to satisfy this need.

![image](https://github.com/user-attachments/assets/13f7c1fb-39e9-4e31-84dc-4a6f7067e70b)

The name of the product indicates that it allows the user to work with **r**eal numbers, **im**aginary numbers, and com**plex** numbers.
